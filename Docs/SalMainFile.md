# Sal Main File Docs

HOW TO USE:
Open the file main_blue_max.py and head to line 42, replace the file name with the one you want to visualize. Run the program and you will get 10 images that pop up in different tabs.

![alt text](refs/track_outline.png)

These images can be used for analysis, as there are 10 generated images. The first 3 are all the lines the gps tracks during a few laps, 1 to 6, 7 to 12, and 13 to 16, then there will be 3 more outputs of the power per lap with the same section of laps.
Then there will be a few more solo images, Speed and Powwer Vs time, track outline by lap, track outline by lap, multiple track dotted outlines on one map, and then an image of the track outline by speed.
