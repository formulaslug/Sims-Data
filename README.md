# Sims-Data

Vehicle Dynamics Simulations and Data Analysis for Formula Slug written from the ground up in python.

You can install dependencies either from pyproject.toml (the requirements.txt is deprecated). The toml is new and may be missing dependencies so if you run into any please let software leadership know. You can install the dependencies by running ```python -m pip install -e .``` (the dot is required, it is not the end of the sentence).
